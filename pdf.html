File

Images → PDF

JPEG and PNG images, one page each, in the order picked. The new pages join the board — save them on their own or with other PDFs.

Pages → images

Each selected page (every page if none is selected) as a PNG or JPEG file.

Scanned pages → searchable (OCR)

Pages that are pictures — scans, photos — are read with the OCR engine Windows already has. The words go into the PDF as an invisible layer on Save, so it searches, copies and extracts like a typed one. Selected pages, or every page; pages that already have text are left alone.

Text → .txt

The text of each page, in reading order, lines kept. Scanned pages are read with OCR.

Tables → Excel / CSV / Parquet

Statements and reports: every text line becomes a row, cut into columns where there is a wide gap. Open the result in the Data module to filter and combine it.
